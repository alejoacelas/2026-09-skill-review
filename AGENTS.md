# Skill review

Scope: a local interface for reviewing immutable outputs from skill trials. Begin with the prepare-to-share comparisons for Morning reader and Writing checks.

Keep original documents and version mappings traceable to exact source commits. Keep user ratings and annotations in ignored local files; never publish them automatically. Serve only the web directory, bind to localhost, and treat imported document text as untrusted content. Changes to the review interface must preserve existing saved feedback.

Verify selection annotations, keyboard navigation, persistence and export in a browser before reporting the interface ready.
